# Marigold Neurocognitive & Mental Health Clinic — Website

A React single-page website for Marigold Clinic, styled with warm orange and cream branding.

## Quick start

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

Static files are output to the `build/` folder for hosting on Netlify, Vercel, GitHub Pages, or any static host.

## Add team photos

Place photos in `public/team/` (e.g. `deso.jpg`) and update `src/components/Hero.js` or team data to reference them.
